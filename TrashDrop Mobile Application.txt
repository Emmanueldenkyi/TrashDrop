TrashDrop Mobile Application
UI/UX Design Documentation

Project Name: TrashDrop – Smart Waste Collection Mobile Application

Platform: Android (React Native)

Design Tool: Figma

Primary Color: Forest Green (#3E6B3A)

Secondary Colors: White, Light Gray, Black

Purpose:
The TrashDrop mobile application allows users to schedule waste pickups, monitor collection status, make payments, receive notifications, and manage their profiles through a clean and user-friendly interface.

Design Principles Used
Simple and intuitive navigation
Consistent green branding for environmental identity
Minimalist interface to reduce user confusion
Clear call-to-action buttons
Readable typography with sufficient spacing
Consistent iconography throughout the application
Responsive layouts suitable for various mobile screen sizes
Immediate feedback for actions such as scheduling and payments
Accessibility through clear contrast and straightforward interactions
